## Selected Projects

### [Arabic Newspaper OCR](case-studies/arabic-newspaper-ocr.md)

A privacy-first Windows desktop application for extracting and reviewing Arabic text from images and PDF documents. It combines a native Qt interface, local Tesseract OCR, document navigation, editable right-to-left text, and a packaged Windows release.

**Technologies:** Python, PySide6, Tesseract OCR, PyMuPDF, Pillow  
**Evidence:** [Repository](https://github.com/pqun7/arabic-newspaper-ocr) · [Release](https://github.com/pqun7/arabic-newspaper-ocr/releases/latest)

### [StoreOps Desktop](case-studies/storeops-desktop.md)

A supporting software engineering project for store operations. The Electron application supports local SQLite or shared PostgreSQL-backed storage, role-aware workflows, automated quality checks, and packaged Windows releases.

**Technologies:** TypeScript, React, Electron, SQLite, PostgreSQL, GitHub Actions  
**Evidence:** [Repository](https://github.com/pqun7/storeops-desktop) · [Releases](https://github.com/pqun7/storeops-desktop/releases)
